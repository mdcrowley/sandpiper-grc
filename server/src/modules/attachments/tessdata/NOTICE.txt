Language data for reading scanned PDFs (OCR, E43-15)

eng.traineddata.gz is eng.traineddata from the tessdata_fast repository of the Tesseract OCR project
(https://github.com/tesseract-ocr/tessdata_fast), compressed with gzip and unchanged otherwise.
SHA-256 of the uncompressed file: 7d4322bd2a7749724879683fc3912cb542f19906c83bcc1a52132556427170b2

It is distributed under the Apache License, Version 2.0 (https://www.apache.org/licenses/LICENSE-2.0).
The application reads it from this folder only; it never downloads language data. To read other
languages, put their <lang>.traineddata.gz files in a folder and set GRC_OCR_LANG_DIR and GRC_OCR_LANGS.
